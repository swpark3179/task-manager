# SCREENS.md — 화면별 명세

각 화면은 `design_files/`의 HTML을 브라우저에서 직접 열어 확인하세요. 값/색/간격은 모두 `TOKENS.md`의 토큰을 사용합니다.

---

## 1. Today — 오늘의 할일
파일: `Today.html` · 로직: `today-app.jsx`, `today-modals.jsx`, `today-data.jsx` · 스타일: `today-styles.css`(`td-*`,`tm-*`,`.md`) + `tokens.css`

### 레이아웃 (세로 스택, 컨테이너 패딩 24px)
1. **Hero** (`.td-hero`) — 카드, 좌우 분할
   - 좌: "오늘의 할일" eyebrow / 큰 날짜(`--text-3xl` 800) + "연도 · 요일" / 진행률 바 + `완료/전체 · %`
   - 우: **동기화 버튼**(`.td-sync`, 클릭→회전 애니 1.1s→"동기화됨"→마지막 시각) 위, **주간 스트립**(이전/다음 주 chevron + 7일, 요일+날짜만, 오늘 강조) 아래. 일·토·공휴일은 색 구분.
2. **공휴일 밴드**(있을 때) — 칩 나열
3. **TabbedCard** (`.td-card`) — 탭 4개 + 본문
   - 탭: **작업 / 일정 / 이벤트 / 나중에 할일** (각 카운트 뱃지). 밑줄형 탭(`.td-tab[aria-selected]`).
   - 탭바 우측: 작업탭=진행률 + 트리/리스트 뷰 토글, 일정탭=`+ 일정 등록`, 이벤트탭=`+ 이벤트 추가`.

### 작업 탭 (`TaskBody` variant="active")
- 빠른 추가 입력(Enter로 추가) + `+ 추가` 버튼
- 상태 필터 pill: 진행(틸)/대기(회색)/완료(초록)/폐기(주황) — 토글 필터. pill과 목록 사이 `margin-bottom:6px`.
- **TaskNode**(재귀): [상태 체크박스][카테고리 색 바][제목/메타][즐겨찾기 별][액션: 펼치기·**상세보기**(문서)·**설정**(톱니)·삭제]
  - 체크박스 클릭: `todo→doing→done→todo`. 부모는 자식 완료수(`n/m`) 표시, 직접 토글 X.
  - 진행 중 행: 틸 틴트 배경. 완료/폐기: 제목 취소선.
  - 펼치기: 상세 미리보기 + 하위 트리.
  - 별: 항상 표시, 활성 시 골드(`--star`).

### 일정 탭 (`ScheduleList`)
- 행: [시간(시작/종료 또는 "종일")][카테고리 바][제목+카테고리 태그+메모][상세보기·설정 아이콘]
- 목록 하단 **`+ 일정 추가`**(`.td-sched-add`, 점선) — 비어 있을 때도 표시.

### 이벤트 탭 (`EventList`)
- D-day 형식: `D-3`/`D-DAY`/`D+1`, 지난 항목은 흐리게. [D라벨][카테고리 바][타입 태그+제목][날짜]

### 나중에 할일 탭 (`TaskBody` variant="later")
- 안내 문구 + `lowPriority:true` 작업 목록(빠른추가/필터 없음)

### 모달 (`today-modals.jsx`) — fixed 오버레이, 중앙 카드(max-width 460, max-height 88vh, 본문 스크롤)
- **작업 편집**(`TaskEditModal`): 작업 이름 · 카테고리(세그) · 나중에 할일(토글). **상세내용 입력 없음** — "상세 내용은 '상세보기'에서 편집" 안내(`.tm-hint-row`).
- **일정 편집**(`ScheduleEditModal`): 제목 · 카테고리 · 시작일 · 종료일 · **예정 시간(토글, 켜면 시작~종료 time)** · **알림(토글, 켜면 [예정시간 전 N분(5/10/30/60) | 특정 시각(time)] 세그)** · 상세내용 입력 없음(안내).
- **상세보기**(`DetailView`): 제목 · 카테고리(·기간) · 마크다운 렌더 본문 + **`상세 편집`** 버튼 → 그 자리에서 마크다운 에디터(작성/미리보기 탭)로 전환 → 저장 시 미리보기 반영(닫지 않음). **상세내용은 여기서만 편집.**

### 상태
`tasks`(트리, setTasks), `schedules`(setSchedules), `events`. 탭/뷰모드/필터, 모달 상태 `{type, item}`. 진행률은 활성(비-나중에) 작업 기준.

## 2. 통합 캘린더 (데스크톱)
파일: `통합 캘린더.html` · 로직: `calendar-unified.jsx`(+ `variation-a.jsx` AppBar/SubBar, `calendar-data.jsx`) · 스타일: `calendar-styles.css`(`cv-*`)

### 레이아웃: AppBar + SubBar + `.cv-C-wrap`(좌 그리드 / 우 사이드 레일 18px gap)
- **AppBar**: 연/월 타이틀, 이전/오늘/다음, `+ 일정 추가`
- **SubBar**: 카테고리 범례·필터(개인/회사/공휴일, 카운트, 토글로 숨김)
- **MonthGrid** (좌): 7열 그리드. 멀티데이 일정 = **레인 바**(셀당 최대 3레인, 초과 시 `+N건 더`). 단일 일정/시간 표시. 공휴일명 표시. 작업 있는 날 = `✓ 할일 N · 미완 M` 칩. 오늘/선택일/일·토 색.
- **SideRail** (우): 선택일 헤더(`일정 N · 할일 M (미완 K)`) + 카테고리 tally + **일정 섹션**(시간·카테고리태그·메모) + **작업 섹션**(상태 dot·제목·상태) + 하단 "이번 달 카테고리" 막대.
- 날짜/막대 클릭 → 선택일 변경(액센트 링 이동).

## 3. 모바일 캘린더
파일: `모바일 캘린더.html` · 로직: `calendar-mobile.jsx`(+ `calendar-data.jsx`, `today-app.jsx`의 `TodayTabs`, `today-modals.jsx`) · 스타일: `calendar-styles.css`(`mcal2-*` 등)

### 레이아웃: 풀스크린 월간 그리드(헤더 + 6주, 화면 가득)
- **헤더**: `연 + 월` 버튼(탭 → **월/연 피커** `mpick`: 연도 스테퍼 + 12개월 그리드), 이전/오늘/다음, **필터 버튼**(`mfilter` 팝오버: "공휴일·기념일·생일" 토글 + 카테고리(개인/회사) 토글 — 일정·작업에 동시 적용).
- **그리드 셀 항목 우선순위**: ①공휴일·기념일·생일 → ②일정(멀티데이=막대) → ③작업, 초과 시 `+n`. 셀 높이는 6주 균등.
- **제스처**(`.mgrid-weeks` 포인터):
  - **탭** → 해당일 **바텀시트** 열림.
  - **좌우 스와이프** → 이전/다음 달(충분히 끌면 확정, 조금이면 스냅백). 스와이프 중 항목 선택 안 됨.
  - **3초 롱프레스** → 기간 선택 모드(드래그로 여러 날 하이라이트) → 손 떼면 **일정 등록 모달**(`msm`)이 해당 기간으로 열림.
- **바텀시트**(`.msheet`): 핸들 드래그로 닫힘(120px↑ 닫기, 부분 드래그는 따라 내려갔다 스냅백). 상단에 선택 날짜, 본문은 **Today의 탭 영역 그대로**(작업/일정/이벤트/나중에 할일) — 따라서 작업/일정 설정·상세보기 모달도 동일하게 동작.
- **일정 등록 모달**(`msm`, 기간선택/FAB용): 제목·카테고리·종일·시간. (Today 탭 내부의 일정 등록은 `ScheduleEditModal` 사용.)

### 표준 스크롤
폰 프레임에서 본문은 네이티브 스크롤(`overflow:auto; touch-action: pan-y; overscroll-behavior: contain`).

## 4. 설정 (데스크톱 + 모바일)
파일: `설정.html`, `모바일 설정.html` · 로직: `settings-app.jsx`(+ `calendar-data.jsx`) · 스타일: `settings-styles.css`(`set-*`)

### 레이아웃: 중앙 컬럼(max-width 560), 섹션 카드 스택. 테마/밀도는 `.set-root`의 `data-theme`/`data-density`로 적용(인스턴스별 독립 프리뷰).
### 섹션
1. **화면**: 테마(라이트/다크 세그, ☀/☾ 아이콘) · 밀도(여유/조밀) · 주 시작 요일(일/월)
2. **동기화**: 자동 동기화(토글) · 동기화 주기(5/15/60분, 자동 off면 비활성) · 수동 "지금 동기화"(마지막 시각)
3. **알림**: 일정 시작 알림(토글+시점 5/10/30분) · 할일 마감 알림(토글)
4. **카테고리**: 행별 [색 dot][이름][편집][삭제(휴지통)] + **`+ 카테고리 추가`**. 추가/편집 모달 = 이름 + **색상 스와치 8종**.
5. **휴일·기념일·생일**: 행별 [구분 배지][제목+날짜(매년이면 "매년 M월 D일")][삭제], 행 탭→편집. **`+ 추가`**. 모달 필드 = **구분(휴일/기념일/생일 세그) · 제목 · 날짜(date) · 매년 반복(토글)**. 월일 순 정렬.
6. **계정**: 아바타+이름+이메일+프로필 / 로그아웃

### 동작
- 테마 세그 → `data-theme` 토글 → 화면 전체 다크 전환(토큰만 교체).
- 밀도 세그 → `data-density` 토글.
- 모달은 설정 컨테이너 기준 오버레이(`set-modal-*`).

## 인터랙션/모션 요약
- 전환: 대부분 `--t-fast`(150ms). 바텀시트 `transform .32s cubic-bezier(.32,.72,0,1)`. 동기화 회전 0.8s linear.
- 포커스 링: `0 0 0 3px var(--accent-soft)`.
- 모달 등장: `translateY/scale` + fade ~0.22s.
- 드래그(시트/스와이프/롱프레스)는 **포인터 이벤트 + ref 기반**(React state 배칭에 안전하도록). 재구현 시 동일 패턴 권장.

## 반응형
- 데스크톱/모바일은 별도 레이아웃(프로토타입은 design_canvas 아트보드로 나란히 비교). 실제 앱에선 브레이크포인트 또는 별도 라우트로 분기.
- 모바일 터치 타깃 ≥ 44px 권장(현재 아이콘 버튼 등은 그에 준함).
- 모바일 그리드는 컨테이너 높이를 flex로 가득 채움(`#root flex:1` 패턴 참고).
